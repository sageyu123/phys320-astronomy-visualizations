# Planet maps (2048x1024, equirectangular, JPEG q85; Venus and Uranus are procedural/schematic)

All files except the two schematic ones (Venus, Uranus) are public domain (NASA/USGS). Originals were converted with sips to 2048x1024; maps whose original was narrower than 2048 px were upscaled (noted). Longitude convention is not stated by most sources; verify visually before relying on it.

Upscaled from 1024x512 (full-res TIF is 760 MB). Enhanced-colour mosaic converted to near-natural grey (saturation x0.2, mean tone ~#8c857c); polar gaps filled (nearest valid pixel per column, blurred).
